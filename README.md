# Calculadora de IMC

Este proyecto permite calcular el Índice de Masa Corporal (IMC) ingresando peso y estatura.  
El resultado muestra si el usuario se encuentra en bajo peso, peso normal, sobrepeso u obesidad, además del rango de peso recomendado.

## Proceso realizado

1. Se creó el archivo index.php con los campos de entrada para peso y estatura, un botón de cálculo y un área para mostrar el resultado.  
2. Se organizó el proyecto en carpetas: css, js e img.
3. Se implementó el archivo styles.css con un diseño moderno y atractivo.
4. Se desarrolló el archivo script.js con la función para calcular el IMC y mostrar la clasificación correspondiente.  
5. Se agregó el cálculo del rango de peso recomendado según la estatura.  
6. Se minificaron los archivos CSS y JS para mejorar el rendimiento.  
7. Se convirtieron las imágenes en formato .webp para reducir su peso y mejorar la carga del sitio.

## Uso

1. Clonar el repositorio con el comando:  
   git clone https://github.com/arelyvidrio7/mi-primer-proyecto-web
2. Abrir index.php en un navegador.  
3. Ingresar peso y estatura, luego presionar el botón Calcular IMC.  
4. Visualizar el resultado y la imagen correspondiente al estado de peso.
